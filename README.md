# 🧊 Nova OS Universe 1.0

**Операционная система будущего с AI-интеллектом**

## Возможности

- 🧠 **AI-планировщик** в ядре Linux
- 🗂️ **NovaFS** — файловая система с AI-дедупликацией
- 🐚 **Nova Shell** — командная оболочка с 2000+ команд
- 🖥️ **Nova Desktop** — графическая среда с AI-братом
- 🤖 **Nova AI** — ИИ-агент с голосом и памятью
- 📦 **nova-pm** — собственный пакетный менеджер
- 🔒 **Квантовая защита** и шифрование

## Системные требования

| Компонент | Минимальные | Рекомендуемые |
|-----------|-------------|---------------|
| Процессор | x86_64, 2 ядра | 4+ ядра |
| ОЗУ | 1 ГБ | 4+ ГБ |
| Диск | 8 ГБ | 32+ ГБ |
| Графика | VESA 2.0 | OpenGL / Vulkan |

## Установка

1. Скачайте ISO с [GitHub Releases](https://github.com/tyuiihggvb/nova-os-universe/releases)
2. Запишите на флешку: `dd if=nova-os.iso of=/dev/sdX bs=4M status=progress`
3. Загрузитесь с флешки
4. Выберите "Установить Nova OS"
5. Следуйте инструкциям
